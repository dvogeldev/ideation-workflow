# Delivery Strategy Format

## Content types (Clief Notes)

See `shared/content-types.md`. Prefer these sections in the strategy doc:

```markdown
## Classroom articles (type 1)
## Announcements (type 2) — paired to articles
## Everyday response sketches (type 3) — optional
## MWP / Software builds — only if build-shaped
```

Use:
- `article-brief-template.md`
- `announcement-brief-template.md`
- `everyday-response-template.md`

---

## MWP Workspace Outline

```markdown
### [Workspace Name]
**Serves:** …
**Pipeline:** …
**Stage count:** …
**Scope / effort / handoff:** …
**Content opportunities:** walkthrough / demo / story / research
```

## Software Outline

```markdown
### [Project Name]
**What it is / approach / decisions / effort / dependencies**
**Content opportunities:** build log / deep-dive / beta
```

## Delivery Sequence Format

```markdown
## Delivery Sequence
### Phase 1: Ship this week
1. **[Article title]** + announcement — Owner — Why first
### Phase 2: Next up
2. …
### Parked
- …
```
