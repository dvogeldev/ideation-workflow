# Brand voices

Each writer (admin + two moderators) has a brand voice file in this folder. Stage 05 article briefs should name an **Owner** and point agents/humans at that owner's voice file when drafting.

| Person | Role | Voice file |
|--------|------|------------|
| David (admin) | Admin | [`david.md`](david.md) |
| Moderator 1 | Mod | [`mod-1.md`](mod-1.md) |
| Moderator 2 | Mod | [`mod-2.md`](mod-2.md) |

Replace the placeholder names/files when you drop in the real documents. Keep one voice per file so assignment stays clean.

## How to use

1. Assign the article brief to an owner in Stage 05.
2. Draft in that person's voice — load only their file, not all three.
3. Do not blend voices in one post unless co-authoring is explicit.
