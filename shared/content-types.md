# Content types (Clief Notes)

The mod team ships **three** distinct deliverables. Stage 05 briefs must pick exactly one type (or a linked set: article + announcement).

| Type | Where it lives | Job | Length | Voice |
|------|----------------|-----|--------|-------|
| **1. Classroom article** | Classroom / course-style long post | Teach one beginner ICM idea end-to-end | One sitting (~5–12 min) | Owner's `shared/voices/` file |
| **2. Announcement / pointer post** | Community feed | Direct members to the classroom article; set context and CTA | Short (≈1–3 short paragraphs) | Same owner as the article when pairing; otherwise assigned owner |
| **3. Everyday response** | Replies on community posts | Unblock one person in-thread; optionally link an article | A few sentences to one short reply | Responder's voice file |

## Rules

1. **Don't blend types** in one draft — an announcement is not a mini-article; a reply is not an announcement.
2. **One voice per draft** — load only that writer's file from `shared/voices/`.
3. **Pairing:** When shipping a new classroom article, produce type 1 + type 2 together. Type 3 is on-demand from live threads.
4. **Everyday responses** may cite a classroom article; they should still answer the specific post first.

## Templates

- Classroom article → `stages/05-strategy/references/article-brief-template.md`
- Announcement / pointer → `stages/05-strategy/references/announcement-brief-template.md`
- Everyday response → `stages/05-strategy/references/everyday-response-template.md`
