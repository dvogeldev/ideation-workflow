# Everyday Response Template

**Content type:** 3 — Everyday reply to a community post

Use when a mod answers in-thread. Not a classroom article. Not a feed announcement.

```markdown
### Everyday response: [Thread topic / member ask]

**Content type:** Everyday response
**Source thread:** [Skool/Discord link or paraphrase]
**Responder:** [David | Mod name]
**Voice file:** `shared/voices/[responder].md`

**What they're stuck on:** [One sentence]
**Reply goal:** [Unblock / clarify / redirect gently / invite to try]

**Reply outline:**
1. Acknowledge their specific situation
2. Give the smallest useful next step
3. Optional link to a classroom article (only if it truly fits)
4. Soft invite to report back

**Optional article to cite:** [title / none]
**Drafting rule:** Load only the responder's voice file. Keep it conversational and short.
```

## When to escalate to an article

If the same stuck point appears 3+ times, open an idea card in the next intake batch instead of only replying forever.
