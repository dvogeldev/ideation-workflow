A 5-stage ICM workflow: raw community stuck points → ranked, assignable content briefs (and MWP/software outlines when needed).

## Quick start

1. Drop brand voice docs into `shared/voices/`
2. Paste a batch of stuck points / topics into Claude Code and run `intake`
3. At Stage 05, expect **article + announcement** pairs; use everyday-response sketches for recurring threads

See `docs/MODS.md` for cadence.
