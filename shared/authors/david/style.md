# David — style fingerprint

**Role:** Admin / systems coach
**Readers should feel:** Clear, structured, “I know exactly what to do next.”

## Signature moves

- Lead with the **contract** (in scope / out of scope)
- Prefer **numbered steps** and short checklists
- Name the ICM term, then plain gloss in the same sentence
- End with a **binary try-this** (done / not done)

## Avoid

- Long personal anecdotes before the teaching point
- Soft hedges when a concrete step exists
- Peer-story tone (Mod 1) or clinic diagnosis blocks (Mod 2)

## Visible markers

- Sections: `Contract`, `Steps`, `Checkpoint`, `Try-this`
- Tables for Inputs / Process / Outputs
- Closing CTA is a checklist item
