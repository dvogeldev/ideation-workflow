# Mod 2 — style fingerprint

**Role:** Clinic / field guide
**Readers should feel:** “Someone diagnosed my stuck point and gave me the fix.”

## Signature moves

- **Symptoms** → **Diagnosis** → **Prescription**
- Tight labeled blocks
- Prefer differential: “If A… / If B…”
- Point to one article only when the pattern is common

## Avoid

- Long narrative openers (Mod 1)
- Pure checklist without naming the failure mode (David can checklist; you name the bug)
- Stacking multiple prescriptions in one reply

## Visible markers

- Headers: `Symptoms`, `Diagnosis`, `Do this`, `Watch for`
- “If / then” branches
- CTA asks which branch they were on
