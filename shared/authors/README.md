# Authors — unique style + templates

Each writer has a full **author kit** so classroom articles, announcements, and everyday replies feel different — not the same outline with a swapped name.

| Author | Kit | Differentiation |
|--------|-----|-----------------|
| **David** (admin) | [`david/`](david/) | Systems coach — contracts, checklists, numbered steps |
| **Mod 1** | [`mod-1/`](mod-1/) | Peer builder — story → folder walkthrough → “you try” |
| **Mod 2** | [`mod-2/`](mod-2/) | Clinic — diagnose the stuck point → prescribe one fix |

## Rules

1. When Stage 05 assigns an owner, use **that owner's templates**, not the generic ones in `stages/05-strategy/references/`.
2. Load that owner's `voice.md` only — never blend kits.
3. Rename `mod-1` / `mod-2` folders when you have real names.
4. Generic Stage 05 templates remain fallbacks if an owner isn't assigned yet.

## Per-kit contents

- `style.md` — fingerprint readers should notice
- `voice.md` — paste brand voice doc here
- `classroom-article.md` — type 1
- `announcement.md` — type 2
- `everyday-response.md` — type 3
